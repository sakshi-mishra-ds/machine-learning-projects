# Customer Risk Analysis Dashboard

A Power BI dashboard project focused on analyzing customer churn, customer risk, service usage, contracts, payment methods, and customer support activity.

## Project Overview

This dashboard provides an interactive view of customer behavior and churn-related patterns.

The report contains two dashboard pages:

- Customer Churn Dashboard
- Customer Risk Analysis Dashboard

The dashboard helps analyze customer churn and identify patterns across internet services, contract types, tenure, payment methods, and customer support tickets.

## Key Performance Indicators

The dashboard includes the following KPIs:

- Total Customers: **7,043**
- Churn Rate: **26.54%**
- Yearly Charges: **16.06M**
- Admin Tickets: **3,632**
- Tech Tickets: **2,955**

## Dashboard Analysis

### Internet Service

The dashboard analyzes customer churn and customer distribution across:

- Fiber Optic
- DSL
- No Internet Service

### Contract Analysis

Customer contracts are analyzed across:

- Month-to-month
- One year
- Two year

### Tenure Analysis

The dashboard provides an interactive tenure filter to analyze customer behavior based on the length of the customer relationship.

### Payment Method Analysis

Customer churn is analyzed across different payment methods, including:

- Electronic Check
- Mailed Check
- Bank Transfer
- Credit Card

### Customer Support

The dashboard also includes:

- Admin Tickets
- Tech Tickets

These metrics help provide additional insight into customer support activity.
